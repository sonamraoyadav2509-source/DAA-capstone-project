MINI-COURIER PLANNER - PROFESSIONAL DESKTOP GUI

Open the Mini_Courier_Planner folder in VS Code.
Open Terminal and run:
  python --version
  python gui.py

The GUI uses Tkinter, which is included with standard Windows Python installations.
The existing algorithm modules and CSV datasets are reused.
Add Parcel saves to data/parcels.csv.
Performance testing saves performance_results.csv.
